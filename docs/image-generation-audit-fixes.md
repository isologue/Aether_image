# 图片请求审计优化说明（2026-10-23）

本轮针对图片输入兼容、无效重试、终态识别、失败记录及账号额度竞态做定点修复。不改变明确内容拒绝“正常返回文字、不重试、不扣费”的约定。

## 实现范围

- 图片请求的确定性输入错误单独分类，返回带 `code`、`param` 的请求错误，不再随切号放大，也不惩罚账号。输入过大返回 413，其他已识别的输入错误返回 400。
- Data URL 显式解析，根据 PNG/JPEG/WebP 文件签名规范化通用 MIME 和声明不匹配的安全栅格格式；不放宽 SVG、任意文件或上游输出的校验。
- 在 ChatGPT Web bootstrap 和任务提交前下载并校验参考图；输入 URL 的确定性 400/401/403/404/410 归类为输入错误。保留 SSRF 和累计内存预算保护，瞬时网络错误不混为输入错误。
- 超长提示词反馈实际 UTF-8 字节数及本地限制，不自动截断或未经验证扩大限制。
- ChatGPT Web 对 `n != 1` 明确返回能力限制，不再误报请求体缺失。没有实现多图拆分、聚合或部分计费；其他提供商继续按其能力归一化。
- 修复同一助手消息的增量 patch 重置终态、一字摘要等问题。EOF/DONE 不能单独证明任务终结，仍结合消息角色、接收方、状态和 end_turn 判断。
- 补充明确内容拒绝识别，保留无图、完整终态及无上游 failure 等约束；拒绝不标记账号异常。
- 持久化脱敏、有界的首次和末次尝试错误；相同候选重复上报去重。失败 usage 缺失 error_message 时填入安全原因或有限错误代码，成功请求不会因为中间重试被标为失败。
- 图片延迟终态及异步 worker 显式传递诊断上下文，减少任务 scope 结束后错误原因、总耗时丢失；保留已知错误状态，避免统一改写成 502。
- 运行时规划失败保留原始请求模型作为兜底；补充解析失败、近期规划未命中和图片规划提前退出的阶段日志，不记录图片内容、凭据或完整提示词。
- 对图片模型使用 `/v1/responses` 但无可用候选给出协议能力说明，不添加模型别名伪装 Responses 支持。
- ChatGPT Web 在 bootstrap 前及上传完成后、提交任务前复核账号可用性。账号本地状态已失效时切下一候选，不伪造上游 401，也不额外惩罚账号。
- 识别到明确额度耗尽错误代码后 CAS 更新额度状态；无已知未来重置时间时使用 300 秒本地退避。额度探测返回时检查元数据快照，避免旧探测覆盖并发本地更新。
- 保留 WebDAV PUT 成功即完成上传的优化，正常出图及后台补传不再完整下载公开图片校验；真实上传失败、本地回退、管理员手动测试保留。

## 尚需确认的边界

1. 约 26.7 MB 的 JSON 编辑请求仅验证了合成输入的解析、归一化和适配器构建；合成 Base64 不是有效图片端到端复现。线上候选创建前退出的根因尚未确认，新增阶段日志用于下次复现，不能宣称根因已修复。
2. 参考图校验位于 Web bootstrap 前，但仍晚于候选选择及 OAuth 准备，不是完整选号前校验。瞬时下载失败也没有跨候选缓存。
3. 账号复核和 CAS 减少竞态，不是原子额度预留；已经在途的并发仍可能遇到同一账号额度不足。目录读取失败时保留原调度结果；尚未做线上规模压测。
4. 新增额度错误代码白名单尚未与此前所有线上额度失败原文逐条对应，不能保证覆盖全部上游变体。
5. 没有实现 Responses 到图片协议隐式转换、提高提示词阈值或多图拆分。
6. 本轮验证不替代部署后端到端验收，也未宣称所有耗时 UI 链路均已重新验证。
